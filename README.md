## Instrucciones rápidas
1. Reemplaza imágenes en `assets/img/` (foto_perfil.jpg, banner.jpg, whatsapp.png).
2. Abre `index.html` localmente o usa Live Server (VS Code).
3. Inicializa git, sube a GitHub y activa GitHub Pages (branch main / root).
4. Valida HTML y toma capturas para el documento de entrega.

## Extras incluidos
- Navegación parcial y carga dinámica con fetch (app.js)
- Modales accesibles
- Validación local de formularios
- Service Worker para cacheo (opcional)
